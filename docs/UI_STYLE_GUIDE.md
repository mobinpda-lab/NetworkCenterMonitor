# UI Style Guide
مرجع بصری پروژه همان طرح نهایی تأییدشده در گفتگو است.
## اصول
- RTL فارسی
- فونت UI: Vazirmatn
- پس‌زمینه روشن/سفید
- Accent اصلی: آبی
- وصل: سبز
- قطع: قرمز
- هشدار/مشکوک/قطعی جدید: نارنجی
- پیگیری: بنفش
- در حال پیگیری: زرد
- غیرفعال/نامشخص: خاکستری
- کارت‌های Rounded، ساده، خلوت و هوشمند
- Bottom Navigation: خانه، قطعی‌ها، پیگیری‌ها، گزارش‌ها، تنظیمات
- ضربه کوتاه: Drill-down
- مکث طولانی: Selection Mode
- دکمه شناور + برای افزودن مرکز، IP، Range و سرویس/Port
## تایپوگرافی گزارش
Report/PDF/Print مستقل از فونت UI و با Vazirmatn UI FD تولید شود. RTL، اتصال حروف، اعداد فارسی، تاریخ شمسی، Embed فونت و یکسانی Preview/PDF/Print جزو معیار پذیرش است.
