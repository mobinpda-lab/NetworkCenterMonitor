# ADR-004 Idea Queue Development Flow

## هدف
جلوگیری از توقف تولید با ورود ایده‌های جدید.

## مسیر رسمی
Idea → Review → Priority Queue → Design → Development → Test → Release

## قوانین
- ایده جدید جایگزین کار جاری نمی‌شود.
- ابتدا با وضعیت موجود تطبیق داده می‌شود.
- از ایجاد Feature یا معماری تکراری جلوگیری می‌شود.
