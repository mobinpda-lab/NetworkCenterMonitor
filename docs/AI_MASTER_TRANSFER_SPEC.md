# NETWORKCENTERMONITOR — AI MASTER TRANSFER SPEC
IDENTITY: NetworkCenterMonitor / NCM | Repo: mobinpda-lab/NetworkCenterMonitor | Platform: Android/Kotlin/Jetpack Compose | Persistence: Room | Async: Coroutines/Flow | Active Monitoring: Foreground Service | Architecture: Local-first, Server-ready.
MISSION: Continuous professional monitoring and management of centers, networks, IPs, devices, services, cameras, recorders, PCs, incidents, history, reports, remote access and recovery; not merely an IP/Port scanner.
AUTHORITY: GitHub Reality + Issues/PRs for implementation/evidence; MASTER_SPEC_V1 v1.1 is canonical product contract; ARCHITECTURE.md is stable architecture authority. Product contract changes require versioned documentation.
PRODUCT PRINCIPLE: Simple UI surface + powerful technical drill-down. Every Center/Network/Device/IP/Service/Camera/NVR/DVR/PC/Incident/Remote Profile has identity/status/history and must be searchable/filterable/reportable/backupable/restorable.
CANONICAL HIERARCHY: Province/Group→Center/Site→Network/VLAN/Range→Device/IP→Service/Port→Incident→FollowUp. Camera: Province→Center→Camera Network→NVR/DVR→Camera. PC: Province→Center→Network→PC→Services/Remote Profiles.
CENTER: province/group/type/address/contact/emergency contact/status/custom fields + computed networks/IPs/devices/services/cameras/recorders/PCs/health/last-check/last-outage/open-incidents/open-followups.
NETWORK: name/type/CIDR/from-to/gateway/subnet/VLAN/access/monitoring/discovery/profile/timeouts/retry/rate-limit. Types General/Camera/Management/Server/VoIP/Industrial/Office/Custom. Access LAN/Private APN/Routed APN/VPN/Route/Port Forward/Local Agent/Custom. Public Internet is not a core dependency.
DEVICE CORE: One canonical Device identity; multiple interfaces/IPs/MACs; device types include network/security/server/PC/workstation/camera/NVR/DVR/storage/UPS/industrial/VoIP/etc. Relations Parent/Child, Connected-To, Managed-By, Recorded-By, Connected-Via, Network-Parent.
SPECIALIZED PROFILES: Camera=Device+Camera Profile; NVR/DVR=Device+Recorder Profile; PC=Device+PC Profile. No parallel identity/data silo.
IP: Independent record with monitoring settings, Device/Center/Network context, notes and multiple services/ports.
CUSTOM FIELDS: Dynamic Text/Number/Date/DateTime/Phone/Boolean/Select/Multi-line; unused fields may hard-delete; used fields disable/archive while preserving historical values.
SERVICES: Independent Service/Port records; TCP/UDP; standard/vendor/custom; independent monitoring configuration.
MONITORING: Global→Group→Center→Network→Device/IP→Service inheritance with lower-level override. Ping/ICMP and Port Monitoring are independent.
MONITORING ENGINE: Queue/Batch/Bounded Concurrency/Worker Pool/Connection Limit/Timeout/Retry/Backoff/Cancellation/Resume. UI never blocks. Restart/resume preserves current state, incidents and history.
RANGE: Manual IP/From-To/CIDR IPv4; Preview count/probes/ports/load before activation; large ranges require bounded concurrency and load estimation.
DISCOVERY: Exactly one shared Discovery Engine for Network/Camera/PC. CIDR/From-To; preview/load estimation; bounded concurrency; rate limit; timeout/retry; pause/resume/stop. Adapters: ARP, ICMP, TCP, UDP, HTTP(S), RTSP, ONVIF, hostname, MAC vendor, service fingerprint, vendor APIs, authenticated inventory, Local Agent.
DISCOVERY DATA POLICY: Auto-discovered values never silently overwrite manual/imported values; conflicts become update proposals.
CAMERA: Vendor-neutral ONVIF T/S/G/M + RTSP/HTTP(S) fallbacks; vendor adapters as extensions. Health Check low-cost/continuous; Snapshot limited/on-demand; Live on-demand; Sub Stream default; Main Stream explicit; stop streams when view closes; bounded concurrent streams.
PC/LAN REMOTE: RDP/Radmin/RustDesk Direct/LAN/VNC/TeamViewer LAN Mode/Custom. Default/Custom/Effective Port distinct; Effective Port drives health/connect/launch. Credentials via secure storage or Ask-on-Connect; plaintext passwords forbidden. LAN/private-network first.
LOCAL SCANNER AGENT: Optional APN/NAT bridge; canonical IDs; LAN discovery/ONVIF/device health/PC inventory/remote detection; metadata/status transfer only; bounded retry/backoff/offline buffering; never own independent DB/Device/Incident/live-stream authority.
INCIDENT LIFECYCLE: Failure→Suspected→Retry→Confirmed→Incident→Recovery→Close; single canonical lifecycle for Device/Camera/PC/Remote failures.
BACKUP/RESTORE: Complete canonical state including networks/VLANs/devices/interfaces/relations/discovery/camera/recorder/PC/remote/manual overrides/agent/incidents/history/followups/settings/custom fields/future attachments. Every new persistent entity requires tested backup/restore coverage.
UI: Persian RTL, Vazirmatn embedded font, simple surface/deep technical detail. Canonical state colors: green connected, red disconnected, amber warning, gray unknown/disabled.
REPORTS: Jalali date/time; Persian RTL; technical drill-down; PDF/Print/Share; history and incident-aware.
