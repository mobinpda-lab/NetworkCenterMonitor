# Production Orchestrator Operating Mode

## هدف
ایجاد مسیر توسعه سریع، موازی و کنترل شده برای NetworkCenterMonitor.

## اصول
- GitHub مرجع وضعیت پروژه است.
- توسعه به Taskهای کوچک تقسیم می‌شود.
- کارهای مستقل موازی اجرا می‌شوند.
- تغییرات معماری قبل از توسعه ثبت می‌شوند.
- مستندسازی همزمان با تغییرات مهم انجام می‌شود.
- ایده‌های جدید وارد صف بررسی می‌شوند و توسعه جاری را متوقف نمی‌کنند.

## چرخه
Idea -> Task -> Development -> Test -> Documentation -> PR -> Quality Gate -> Merge

## گزارش‌دهی
گزارش‌ها کوتاه و فقط شامل وضعیت واقعی، مانع و مرحله بعد هستند.

## توجه
این سند تعریف فرآیند است و به‌تنهایی نشانه تکمیل اتوماسیون 100 درصد نیست؛ اجرای واقعی هر مرحله باید evidence داشته باشد.
