# NetworkCenterMonitor
سامانه اندرویدی پایش مراکز و ارتباطات شبکه، مدیریت قطعی‌ها، پرونده IP/سرویس، پیگیری، گزارش‌گیری و پشتیبان‌گیری کامل.
## مرجع محصول
سند Canonical نیازمندی‌ها: `docs/MASTER_SPEC_V1.md`
## وضعیت
این Repository برای آغاز توسعه نسخه 1.0 آماده شده است. معماری هدف: Kotlin + Jetpack Compose + Room، Local-first و Server-ready.
## اصول کلیدی
- UI فارسی RTL با Vazirmatn
- گزارش/PDF/Print با Vazirmatn UI FD
- سبز=وصل، قرمز=قطع، نارنجی=هشدار، بنفش=پیگیری، خاکستری=غیرفعال
- ساختار داده: استان/گروه → مرکز → IP → سرویس/Port → Incident → پیگیری
- Backup/Restore کامل تمام اطلاعات و تنظیمات
- تمام زمان‌های قابل نمایش همراه تاریخ هجری شمسی
